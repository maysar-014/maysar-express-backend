# Maysar Express Backend - Security & Architecture Remediation Plan

## Executive Summary

This document outlines a comprehensive plan to address critical security vulnerabilities and architectural issues identified in the Maysar Express Backend codebase. The current system has multiple production-blocking issues that must be resolved before deployment.

## Current Risk Assessment

### Critical Issues (P0) - Immediate Showstoppers

#### 1. Unprotected Public APIs / No Authentication
**Location**: All service endpoints
**Risk**: Complete unauthorized access to sensitive operations
**Evidence**: No JWT/auth middleware in service entrypoints
**Impact**: Financial loss, data manipulation, fraud

#### 2. Broken Route Definitions / Non-functional APIs
**Location**: services/inventory-service/src/index.ts (lines 41-51)
**Risk**: APIs silently fail, broken user flows
**Evidence**:
```typescript
// BROKEN: This never matches
if (req.method === 'GET' && req.path === '/:variantId')
```
**Impact**: Service appears functional but all APIs return 404

#### 3. Database Credentials in Plaintext + Exposed Ports
**Location**: docker-compose.yml
**Risk**: Credential leakage, unauthorized DB access
**Evidence**:
```yaml
POSTGRES_PASSWORD: maysar_password  # Hardcoded
ports:
  - "5432:5432"  # Exposed to host
  - "6379:6379"  # Exposed to host
```

#### 4. In-Memory EventBus / Non-scalable Architecture
**Location**: services/compliance-service/src/index.ts
**Risk**: Events lost on restart, no horizontal scaling
**Evidence**:
```typescript
const eventBus = new EventBus(); // In-memory only
```

#### 5. Duplicate Background Jobs / setInterval Scaling Issues
**Location**: Multiple services using setInterval
**Risk**: Jobs run multiple times when horizontally scaled
**Evidence**:
```typescript
setInterval(() => { /* compliance checks */ }, 24 * 60 * 60 * 1000);
```

### High Priority Issues (P1)

#### 6. Missing Security Middleware & Input Validation
**Evidence**: No helmet, cors, rate-limiting, input validation libraries
**Risk**: Injection attacks, DoS, unauthorized access

#### 7. No CI/CD Pipeline or Testing
**Evidence**: package.json test script: "Error: no test specified"
**Risk**: Unreliable releases, undetected regressions

#### 8. Incomplete Prisma Setup & Migrations
**Evidence**: Empty prisma/ directory, missing migration scripts
**Risk**: Schema drift, manual SQL usage

#### 9. Frontend Dependencies Mixed in Backend

**Task**: Implement centralized JWT auth
**Files**: src/middleware/auth.ts (new)

```typescript
import jwt from 'jsonwebtoken';
import { Request, Response, NextFunction } from 'express';

interface AuthRequest extends Request {
  user?: any;
}

export const authenticateToken = (
  req: AuthRequest,
  res: Response,
  next: NextFunction
) => {
  const token = req.headers['authorization']?.split(' ')[1];
  if (!token) return res.sendStatus(401);

  jwt.verify(token, process.env.JWT_SECRET!, (err, user) => {
    if (err) return res.sendStatus(403);
    req.user = user;
    next();
  });
};

export const requireRole = (roles: string[]) => {
  return (req: AuthRequest, res: Response, next: NextFunction) => {
    if (!req.user || !roles.includes(req.user.role)) {
      return res.sendStatus(403);
    }
    next();
  };
};
```

### Phase 1C: Event Bus & Background Jobs (Week 1-2)

#### Priority 6: Replace In-Memory EventBus (6 hours)
**Task**: Implement Redis-based distributed event bus
**Files**: src/events/redisEventBus.ts (new)

```typescript
import { Redis } from 'ioredis';

export interface EventData {
  eventId: string;
  eventType: string;
  timestamp: Date;
  payload: any;
}

export class RedisEventBus {
  private redis: Redis;
  private subscribers: Map<string, Function[]> = new Map();

  constructor(redisUrl: string = process.env.REDIS_URL || 'redis://localhost:6379') {
    this.redis = new Redis(redisUrl);

    this.redis.on('message', (channel, message) => {
      try {
        const event: EventData = JSON.parse(message);
        const handlers = this.subscribers.get(channel);
        if (handlers) {
          handlers.forEach(handler => {
            try {
              handler(event);
            } catch (error) {
              console.error(`Error in event handler for ${channel}:`, error);
            }
          });
        }
      } catch (error) {
        console.error('Error parsing event message:', error);
      }
    });
  }

  async publish(eventType: string, payload: any): Promise<void> {
    const event: EventData = {
      eventId: `${eventType}-${Date.now()}-${Math.random()}`,
      eventType,
      timestamp: new Date(),
      payload
    };

    await this.redis.publish(eventType, JSON.stringify(event));
  }

  subscribe(eventType: string, handler: (event: EventData) => void): void {
    if (!this.subscribers.has(eventType)) {
      this.subscribers.set(eventType, []);
      this.redis.subscribe(eventType);
    }
    this.subscribers.get(eventType)!.push(handler);
  }

  async close(): Promise<void> {
    await this.redis.quit();
  }
}
```

#### Priority 7: Distributed Job Scheduler (6 hours)
**Task**: Implement leader election for background jobs
**Files**: src/scheduler/distributedScheduler.ts (new)

```typescript
import { Redis } from 'ioredis';

export class DistributedScheduler {
  private redis: Redis;
  private instanceId: string;
  private isLeader = false;
  private leaderKey = 'scheduler:leader';
  private leaderTTL = 30; // seconds

  constructor(redisUrl: string = process.env.REDIS_URL || 'redis://localhost:6379') {
    this.redis = new Redis(redisUrl);
    this.instanceId = `scheduler-${Date.now()}-${Math.random()}`;

    // Start leader election
    this.startLeaderElection();

    // Periodic leader check
    setInterval(() => this.checkLeadership(), 10000);
  }

  private async startLeaderElection(): Promise<void> {
    try {
      const result = await this.redis.set(
        this.leaderKey,
        this.instanceId,
        'NX', // Only set if key doesn't exist
        'EX', // Set expiry
        this.leaderTTL
      );

      this.isLeader = result === 'OK';

      if (this.isLeader) {
        console.log(`Instance ${this.instanceId} became leader`);
        this.startScheduledJobs();
      }
    } catch (error) {
      console.error('Error in leader election:', error);
    }
  }

  private async checkLeadership(): Promise<void> {
    try {
      const currentLeader = await this.redis.get(this.leaderKey);

      if (currentLeader === this.instanceId) {
        // Extend leadership
        await this.redis.expire(this.leaderKey, this.leaderTTL);
        if (!this.isLeader) {
          console.log(`Instance ${this.instanceId} regained leadership`);
          this.isLeader = true;
          this.startScheduledJobs();
        }
      } else if (this.isLeader) {
        console.log(`Instance ${this.instanceId} lost leadership`);
        this.isLeader = false;
        this.stopScheduledJobs();
      }
    } catch (error) {
      console.error('Error checking leadership:', error);
    }
  }

  private startScheduledJobs(): void {
    // Daily compliance checks
    this.scheduleJob('compliance-check', 24 * 60 * 60 * 1000, async () => {
      // Publish compliance events
      await this.eventBus?.publish('DataRetentionCheck.v1', {});
      await this.eventBus?.publish('PCIVulnerabilityScan.v1', {});
      await this.eventBus?.publish('SOXComplianceCheck.v1', {});
    });

    // Quarterly KYC checks
    this.scheduleJob('kyc-check', 90 * 24 * 60 * 60 * 1000, async () => {
      await this.eventBus?.publish('KYCExpiryCheck.v1', {});
    });

    console.log('Scheduled jobs started');
  }

  private stopScheduledJobs(): void {
    // Clear any running intervals
    // Implementation depends on how jobs are scheduled
    console.log('Scheduled jobs stopped');
  }

  private scheduleJob(name: string, interval: number, job: () => Promise<void>): void {
    setInterval(async () => {
      if (this.isLeader) {
        try {
          await job();
        } catch (error) {
          console.error(`Error in scheduled job ${name}:`, error);
        }
      }
    }, interval);
  }

  async close(): Promise<void> {
    if (this.isLeader) {
      await this.redis.del(this.leaderKey);
    }
    await this.redis.quit();
  }
}
```
