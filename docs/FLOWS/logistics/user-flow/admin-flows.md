## Overview

This document covers logistics-service admin/ops endpoints used for lifecycle verification, testing, and operational tooling. These endpoints are **not intended for production frontend UIs** — they are internal tools for platform operators and automated test suites.

## Flow 1: Seed COD Delivery

> ✅ **MSS-002 — Added 2026-11-06** (`services/logistics-service/index.ts`).
> Creates a `logistics_Delivery` row with `isCOD: true` directly via Prisma. Required because the standard delivery creation endpoint (`POST /api/logistics/api/v1/deliveries`) does not accept COD flags, and COD OTP verification requires a delivery that is flagged as COD.

### Summary

| Field | Value |
|---|---|
| Actor | Admin |
| Trigger | Lifecycle verification / testing needs a COD delivery to exercise the OTP flow |
| Preconditions | Authenticated (Bearer JWT, admin role); `orderId`, `buyerId`, `sellerId` must be valid user/order IDs |
| Terminal states (success) | 201 — `logistics_Delivery` row upserted with `isCOD: true`, status `assigned` |
| **Production use** | ❌ Internal tooling only — do not expose to any frontend UI |

### Happy Path

| Step | Actor/System | Action | Endpoint | Auth | Expected Response |
|---|---|---|---|---|---|
| 1 | Admin / Test | Create COD delivery | `POST /api/logistics/admin/cod-delivery` | Bearer JWT (admin) | 201 `{ success: true, data: { deliveryId, isCOD: true } }` |
| 2 | System | Upserts `logistics_Delivery` row | — | — | Row idempotent — same `orderId` always produces same `deliveryId` |

### Request Body

```json
{
  "orderId": "ord_...",
  "courierId": "usr_...",
  "buyerId": "usr_...",
  "sellerId": "usr_...",
  "codAmount": 15000
}
```

`courierId` defaults to the seeded courier (`usr_01KRFZ1E7W4JDR9N9PMGYDD77S`) if omitted. `codAmount` defaults to 15000 TZS.

### Idempotency

The delivery ID is derived deterministically from `orderId` via a stable hash. Calling this endpoint twice with the same `orderId` upserts the same row — no duplicate deliveries.

### Unhappy Path Branches

| Trigger | System Response |
|---|---|
| Missing `orderId`, `buyerId`, or `sellerId` | 400 `{ success: false, error: "orderId, buyerId, sellerId are required" }` |
| `logistics_Delivery` Prisma model not available | 503 |
| Caller is not admin | 401/403 |

## Flow 2: Read Delivery OTP (Non-Production Only)

> ✅ **MSS-003 — Added 2026-11-06** (`services/logistics-service/index.ts`).
> Reads the OTP stored on a delivery row after the `CODInitiationSaga` runs. The `POST .../otp` endpoint deliberately does not return the OTP in its response (it goes out-of-band to the buyer via notification). This admin endpoint allows lifecycle tests and ops tooling to read it back.

### Summary

| Field | Value |
|---|---|
| Actor | Admin |
| Trigger | After calling `POST /api/logistics/api/v1/cod/:deliveryId/otp`, read the OTP that was saved to the delivery row |
| Preconditions | `NODE_ENV !== 'production'`; authenticated (Bearer JWT, admin role); delivery row exists; OTP has been generated by the saga |
| **Production use** | ❌ Returns 403 in `NODE_ENV=production` — intentional |

### Happy Path

| Step | Actor/System | Action | Endpoint | Auth | Expected Response |
|---|---|---|---|---|---|
| 1 | Admin / Test | Read OTP from delivery row | `GET /api/logistics/admin/deliveries/:deliveryId/otp` | Bearer JWT (admin) | 200 `{ success: true, data: { otp, otpExpiresAt, status, isCOD } }` |

### Response Shape

```json
{
  "success": true,
  "data": {
    "otp": "123456",
    "otpExpiresAt": "2026-11-06T12:30:00.000Z",
    "status": "in_transit",
    "isCOD": true
  }
}
```

`otp` is `null` if the saga has not yet run or failed to persist the code.

### Timing

The COD initiation saga is asynchronous. After calling `POST .../otp`, allow 1–3 seconds before polling this endpoint. The lifecycle script retries twice with 2s and 3s delays.

### Unhappy Path Branches

| Trigger | System Response |
|---|---|
| `NODE_ENV=production` | 403 `{ success: false, error: "Not available in production" }` |
| Delivery not found | 404 |
| `logistics_Delivery` model not available | 503 |
| Caller is not admin | 401/403 |
